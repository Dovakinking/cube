# cube
Нарисуйте от руки или в графическом редакторе проекцию равностороннего куба с прозрачными стенками (см. рис.). Сфотографируйте изображение нанесённого от руки или распечатанного рисунка. Разработайте программу поиска вершин и рёбер куба на изображении.

<img src="cube_dataset\images\main_cube.png" width="700"/>

## Структура репозитория:

```
├── README.md                     <- текущее описание проекта
├── fons                          <- варианты фонов для генерации
│   ├── fon_1.png
│   ├── ...        
│   └── fon_20.jpg
├── test                          <- нарисованные руками кубы для тестов
│   ├── test.jpg                
│   ├── test2.jpg
│   ├── ...        
│   └── test13.png
├── cube_dataset                  <- датасет и разметка
│   ├── annotations               <- COCO-аннотации для обучения и валидации
│   │   ├── coco_keypoints.json
│   │   └── coco_keypoints_clear.json
│   ├── images                    <- основной датасет
│   │   ├── cubes                 <- сгенерированные изображения кубов
│   │   ├── cubes_clear           <- кубы без лишних шумов
│   │   ├── points                <- изображения с истиными точками из аннотации
│   │   ├── points_save           
│   │   └── predicts              <- визуализация предсказаний модели
│   ├── main_cube.png             <- кубик из условия
│   ├── mse_results.csv           <- результаты метрик по предсказаниям 1 - 3000 индексы - первая модель
│   ├── mse_results_2.csv         <- 3001 - 7000 индексы - вторая (основная модель)
│   └── mse_results_3.csv         <- 7001 - 11000 индексы - третья модель, хуже, чем вторая
├── cube_generator6_0.ipynb       <- совмещённый ноутбук для генерации датасета и обучения модельки
├── real_time_test4_0.ipynb       <- предсказания в реальном времени
└── finetuned_cube_model_2.pth    <- обученная финальная моделька с точностью 93.5 %
```
